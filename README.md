# 김동영 | Backend Developer

Java와 Spring Boot로 웹 서비스를 개발합니다. DunTalk의 백엔드를 설계·구현하고 배포·운영하며, 데이터 수집과 조회 성능을 개선하고 있습니다.

## 대표 프로젝트

### [DunTalk](https://github.com/kdyddd/duntalk)

던전앤파이터 아이템 시세를 수집·집계하고 정보를 나누는 커뮤니티 서비스입니다.

- **담당:** 개인 프로젝트 · 백엔드 설계·구현 · 배포·운영
- **기술:** Java 17, Spring Boot, Spring Data JPA, Spring Security, MySQL, AWS EC2, Nginx
- **외부 API 수집:** 비동기 병렬 호출과 호출량 제한을 적용하고, 측정 결과에 따라 운영 스레드 수를 선정했습니다.
- **조회 성능:** 실행 계획 분석과 통계 데이터 보관 정책으로 시세 조회 지연을 개선했습니다.
- **커뮤니티:** 게시글·댓글 조회의 N+1 문제를 개선하고, Google 로그인과 게임 캐릭터 소유 검증을 구현했습니다.

[서비스 보기](https://duntalk.kr/) · [설계·개선 과정과 측정 결과](https://github.com/kdyddd/duntalk#핵심-설계와-개선)
